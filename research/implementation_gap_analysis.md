## Streaming constraints in the evaluated FullSubNet path

The adapter config sets `look_ahead=2`. At 16 kHz and a 256-sample hop, two future frames correspond to 32 ms of model look-ahead, before STFT buffering, frame scheduling, processing and audio I/O. In addition, the selected `offline_laplace_norm` normalizes using utterance-wide statistics, so a chunked call cannot preserve the same behavior without future utterance samples. The upstream cumulative normalization option changes the operating mode; it is not evidence that epoch 58 with offline normalization is causal. A true live variant requires explicit causal normalization/state, bounded buffers, chunk-boundary equivalence checks and separate quality/latency evaluation.

## Low-SNR observed failure signature

The current evidence localizes the problem, not its unique cause: at -10 dB, the protected model averages STOI .677/PESQ-WB 1.386 and has 0/30 joint passes; at -5 dB it has 3/63 joint passes. FullSubNet raises low-bin scores but still has 0/30 and 2/63. Both systems see a single-channel mixture. When speech and interference occupy the same time-frequency region, suppression may attenuate weak phonetic detail with the noise; an impulse can also dominate perceived quality despite good broadband error reduction. Gunfire-origin data dominate low-SNR groups, confounding source/domain with level. Direct evidence of speech deletion, transient residuals, or mask behavior is not yet collected, so this is a physically plausible hypothesis, not a confirmed root-cause diagnosis.
