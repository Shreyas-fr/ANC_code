## Key findings

1. GTCRN is a real official upstream implementation, rather than a model name appearing only in a benchmark README. Its upstream repository advertises a usable pretrained inference path and streaming assets. However, nothing is installed or present locally, and the SIH benchmark runner itself does not reproduce its listed numbers.
2. Project AURA offers plausible compression/distillation ideas, but its README results and hardware statements are not independently verifiable here. The noted speaker overlap is a reproducibility concern for interpreting its test numbers.
3. FullSubNet is supported by local source, checkpoint, exact config, manifest linkage and the completed project evaluation. It is offline-only in the configuration actually evaluated.
4. NRSRNet and dual-channel ANC remain research directions, not local model implementations or demonstrated system features.

## Scope / restrictions observed

No external source code or model weights were written into the workspace. No training audio, checkpoints or notebooks were uploaded. No Kaggle or Raspberry Pi access occurred. No gold-test content was accessed. Links above point to public primary sources; external project metrics are explicitly treated as claims.
